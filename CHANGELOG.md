# Changelog

All notable changes to the VideoTranscriber project will be documented in this file.

## [2.0.0] - 2025-06-06

### Added
- Multi-language support with automatic language detection
- Natural video understanding with automatic monitoring of `./video_inputs/` folder
- Context-aware suggestion engine for intelligent follow-up questions
- Interactive and animated onboarding experience
- Video library interface for managing multiple videos
- Knowledge base for storing and retrieving video content
- Welcome modal with step-by-step guidance
- Help button for accessing tours at any time

### Changed
- Redesigned user interface with improved navigation
- Enhanced chat interface with context-aware suggestions
- Improved transcript analysis with action points extraction
- Updated PDF generation with language-aware formatting

### Fixed
- Various UI/UX improvements for better usability
- Performance optimizations for handling larger video files
- Improved error handling and user feedback

## [1.0.0] - 2025-01-01

### Added
- Initial release with basic video transcription
- Simple chat interface for asking questions about transcripts
- PDF export functionality
- Basic transcript analysis
